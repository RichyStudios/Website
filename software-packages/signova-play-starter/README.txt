SIGNOVA PLAY STARTER 1.0

Quick start:
1. Double-click index.html to play directly in a browser.
2. Edit index.html, style.css, and game.js to make the game your own.
3. If you have Python installed, run: python server.py
4. Open http://localhost:8080

Controls: Arrow keys or WASD. Touch the arrow buttons on a phone or tablet.
